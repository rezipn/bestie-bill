# Bestie Bill 🧾

Patungan tanpa drama: foto struk, bagi rata, langsung ketahuan siapa bayar siapa.

> 🚧 **Masih dalam proses (work in progress).**
> Alur utama sudah jalan: buat grup → upload struk / input item manual → hitung patungan → share ke WhatsApp.
> OCR struk (Tesseract.js) masih dituning — hasil baca bisa meleset, koreksi manual tersedia di halaman Upload.

## Stack
- Frontend: Angular (standalone, SCSS, Poppins)
- Backend: Node.js + Express (`/server`, endpoint `/api/split`)
- OCR: Tesseract.js (gratis, jalan di browser)
